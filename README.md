# Hindi Academic Terminology (Draft)

An English-Hindi academic terminology resource with equivalents, lexical clusters, grammar notes, usage evidence and example sentences.

## Status and disclaimer
This is a work-in-progress research dataset. Entries are drafts and may contain errors, including in Hindi terms, grammar notes, translations and source details. It is not an official standard and is not endorsed by CSTT or any institution. It is provided "as is", without warranty of any kind. The author accepts no responsibility for any loss or consequence arising from its use. Please check authoritative sources before relying on it for exams, translation work, or legal, financial or professional purposes.

## Corrections welcome
Found a mistake or a better source? Please open an issue on this repository or write to soni362002@gmail.com. Corrections are appreciated and will be credited where you wish.

## Structure
- `entries/` one JSON file per term sense
- `sentences/` example sentence pairs (JSONL)
- `counter.txt` last entry number used
